# **App Name**: Pustaka Cepat

## Core Features:

- Book Idea Generation: Generate 5-10 book ideas based on user-defined categories, audience, and goals.
- Structured Outline Creation: Create a structured book outline with 8-12 chapters, subheadings, objectives, and glossary terms.
- Chapter Content Generation: Write complete chapters based on the outline, with inline citations and a word count of 800-1200 words per chapter.
- APA Citation Insertion: Automatically insert citations inline in APA format, using a predefined list of references.
- Islamic Category Support: Insert relevant Quranic verses or Hadith in Arabic with short translations, using predefined data.
- APA Bibliography Compilation: Compile a final APA 7th edition bibliography from all references used in the book.
- Draft Saving: Save intermediate work drafts as document formats.

## Style Guidelines:

- Primary color: Indigo (#556BF3) for main actions and links, conveying trust and intellect. 
- Background color: Light gray (#F8FAFC), subtly of the same hue as indigo, creates a soft and clean surface, making the content readable.
- Accent color: Teal (#2EC5B6), analogous to indigo but different in brightness, for progress indicators and success states, offering a fresh, technological vibe.
- Headings font: 'Source Serif 4', a serif typeface with a distinguished and literary feel for chapter titles and section headings.
- UI & Body font: 'Inter', a versatile sans-serif font that ensures readability and modern appeal for body text and user interface elements.
- Arabic font: 'Amiri' or 'Noto Naskh Arabic' is used when islamic is selected as a category, for proper display and readability of Arabic scripture excerpts.
- Use educational and thematic icons to represent categories, actions, and steps throughout the user interface, aiding intuitive navigation.
- In the Ideation page layout, left side has Topik, Audience, and Purpose options, right panel with "Generate Ide" button above resulting list.
- Employ subtle transitions and animations when generating new sections of content, providing a sense of progress and engagement for the user.
